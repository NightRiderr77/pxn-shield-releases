## Windows

Two ways to get it, from the [latest release](https://github.com/NightRiderr77/pxn-shield-releases/releases/latest):

- **Setup** — `PXN-Shield-VPN-Setup-x.y.z.exe`. Installs, adds a shortcut, done.
- **Portable** — `PXN-Shield-VPN-Portable-x.y.z.zip`. Unzip anywhere and run `PxnShield.exe`. Nothing is written outside the folder.

Windows 10 or 11, 64-bit. Everything the app needs is inside, so there is no runtime to install first. It asks for administrator because creating a network adapter needs it.
